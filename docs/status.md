## 已建立的项目知识

- `exhibits/*/exhibit.yaml` 是展品事实的单一来源，目前有 24 条记录。
- `collections/readme.yaml` 和 `collections/gallery.yaml` 负责不同出口的选择、分组与顺序。
- YAML 是人工编辑的规范格式；通过 Schema 与跨文件校验后生成 README、`generated/catalog.json` 和 `generated/assets.json`。
- `ASSETS.yml` 区分远程候选与批准入库的共享素材；展品专属素材归对应展品记录管理。
- 网络公开不等于允许再分发。来源、作者、权利依据、署名、隐私复核和哈希必须跟随本地素材。
- 二期游戏的数据应放在未来的 `scenes/*.yaml` 中，通过展品 ID 引用目录，不复制展品事实。

完整决策和目录职责见 [项目决策](project-decisions.md)。
